# Decisión de cierre sobre la alternativa integral

## Estado

El proyecto se declara **viable condicionado**. Cloud/GCP es la alternativa integral recomendada para el piloto, con TCO oficial de CLP 10.815.487 a 36 meses. La recomendación no equivale a autorización de ejecución: requiere cumplir los gates éticos CA-E01 a CA-E10, legales, técnicos, de seguridad, de riesgos y de validación local.

## Evidencia por alternativa

| Alternativa | A favor | Restricciones y riesgos que deben resolverse |
|---|---|---|
| Cloud/GCP | Seleccionada: menor TCO oficial, CAPEX bajo y escalabilidad gestionada. | Ejecutar sólo con autorización y gobierno de datos aplicables, controles de privacidad y seguridad, aceptación de riesgos y validación local. |
| Local | Técnicamente viable y con control físico directo. | No recomendada para este piloto por CAPEX/TCO y carga de mantenimiento, continuidad, seguridad y personal especializado. |
| Híbrida | Contingencia si Cloud no supera aprobación legal, institucional o de gobierno de datos. | Sincronización, transferencia, seguridad y operación dual; mayor RRHH y TCO que Cloud. |

## Gates antes de ejecutar el piloto

1. Cumplir CA-E01 a CA-E10 como condiciones formales de aceptación ética.
2. Contar con autorización y análisis legal/gobierno de datos aplicables; no se declara cumplimiento legal definitivo.
3. Confirmar controles de seguridad, continuidad, operación y aceptación de riesgos.
4. Validar con datos y flujo clínico locales; no trasladar automáticamente resultados del dataset académico.
5. Definir el riesgo residual de R10 si corresponde; no se infiere en este informe.

## Decisión adoptada

Cloud/GCP queda seleccionada como arquitectura integral recomendada para el piloto condicionado. La alternativa Híbrida se activa como contingencia ante una no aprobación legal, institucional o de gobierno de datos de Cloud. Local no se recomienda para este piloto.
