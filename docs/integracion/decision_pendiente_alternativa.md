# Decisión pendiente sobre la alternativa integral

## Estado

Cloud es la alternativa financieramente preferida, con TCO estimado de CLP 10.815.487 a 36 meses. Esta evidencia no cierra la recomendación integral.

## Evidencia por alternativa

| Alternativa | A favor | Restricciones y riesgos que deben resolverse |
|---|---|---|
| Cloud | Menor TCO estimado, CAPEX bajo y escalabilidad gestionada. | Autorización para datos sensibles en GCP, controles de privacidad, dependencia de proveedor/conectividad y validación local. |
| Local | Mayor control físico e identidad/datos en el hospital. | CAPEX, mantenimiento, continuidad, ransomware, personal especializado y respaldo de cotizaciones. |
| Híbrida | Conserva identidad y registro maestro locales; mantiene elasticidad analítica. | Sincronización, transferencia, seguridad y operación dual; mayor RRHH y TCO que Cloud. |

## Condiciones antes de decidir

1. Conciliar TCO Cloud de Finanzas con el valor heredado en Riesgos.
2. Contar con autorización y análisis legal/gobierno de datos aplicables.
3. Confirmar controles de seguridad, continuidad y operación para la alternativa elegida.
4. Validar con datos y flujo clínico locales; no trasladar automáticamente resultados del dataset académico.
5. Revisar riesgos críticos, responsables y riesgo residual con Vicente.

## Decisión requerida

El equipo debe seleccionar la alternativa integral después de evaluar estas condiciones. Esta nota no asigna ponderaciones ni declara una arquitectura ganadora.
