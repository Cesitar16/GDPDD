# Decisión de alcance vigente

La línea base vigente es el plan académico de diez semanas descrito por el informe EP3 corregido, con un presupuesto estimado de CLP 10.506.069. El entregable es un prototipo de investigación y demostración, no una plataforma institucional ni un producto clínico.

La comparación y selección previa de alternativas Cloud, Local e Híbrida se retira como decisión de arquitectura vigente. El repositorio actual ejecuta entrenamiento local con GPU y una automatización batch de ejemplo; no acredita despliegue GCP, infraestructura hospitalaria, integración institucional ni costos de operación posterior.

El informe 3.2.2 aporta un ejercicio académico de monitoreo/control. Sus fechas, tarjetas, estados y horas simulados se documentan separadamente y no reemplazan la planificación EP3 ni prueban ejecución material.
