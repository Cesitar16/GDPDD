\section{Organización y estado de ejecución}
\label{sec:gobernanza-ejecucion}

La actividad se organiza con los marcos académicos indicados en los informes: PMBOK para documentar alcance, decisiones y riesgos; Scrum para ordenar el trabajo en periodos breves; y CRISP-DM para estructurar el análisis de datos y modelado. La documentación de estos marcos describe el método; no acredita que exista un equipo clínico, patrocinador institucional ni ceremonias formales ejecutadas.

\subsection{Elementos que no constan como ejecutados}

No se encontró evidencia en el repositorio de aplicación web, API, base de datos institucional, integración con ficha clínica, carga de datos desde hospital, despliegue cloud, revisión clínica, aprobación institucional, validación con población local, monitoreo en producción o reentrenamiento posterior. Las menciones a esos componentes en entregas académicas antiguas describen propuestas; no deben leerse como avances.

El informe 3.2.2 incluye una simulación didáctica de seguimiento. Sus estados, horas y cambios no se contabilizan como trabajo ejecutado salvo que exista evidencia independiente en el repositorio. El estado actual se limita a los archivos, resultados y artefactos identificados en esta documentación.
