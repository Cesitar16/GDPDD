\subsection{Criterios de aceptación de riesgos}

La matriz satisface los criterios definidos por su fuente: diferencia riesgos técnicos, legales, financieros y éticos; mantiene una escala consistente de probabilidad e impacto; y vincula cada riesgo con una mitigación y un responsable. Las mitigaciones se alinean con la arquitectura Cloud propuesta, el TCO base indicado por la fuente y el plan de RRHH. Los riesgos críticos R01, R02, R03, R07 y R10 deben revisarse en los gates correspondientes antes de avanzar al piloto o a una nueva versión del modelo.

\subsection{Consistencia financiera pendiente de validación}

La fuente de riesgos menciona un TCO base Cloud de \$11.866.338, mientras que el anexo financiero documenta un TCO Cloud de \$10.815.487. Esta diferencia se conserva explícitamente como elemento abierto: antes de la aprobación financiera se debe conciliar la base de cálculo, el IVA, la contingencia y las partidas de RRHH para que la matriz de riesgos y el presupuesto usen la misma línea base.
