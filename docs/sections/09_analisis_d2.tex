\section{Arquitectura y herramientas cloud (antecedente D2)}

La comparación de plataformas Cloud de documentos anteriores pertenece a un alcance institucional que ya no está vigente. El repositorio actual no despliega el modelo en GCP ni requiere servicios gestionados para completar la actividad de diez semanas. El entrenamiento documentado se realiza localmente con XGBoost y CUDA; la inferencia de ejemplo corre mediante un script local sobre CSV.

Por trazabilidad se conserva el análisis conceptual previo de servicios y riesgos, pero no constituye arquitectura seleccionada, decisión de compra ni compromiso de implementación del alcance vigente. La nube, Vertex AI y cualquier plataforma MLOps quedan fuera del estado implementado.
