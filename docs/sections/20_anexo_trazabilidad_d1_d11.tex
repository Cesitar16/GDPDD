Las alternativas Cloud, Local e Híbrida, el dimensionamiento institucional, las ventanas recurrentes y los SLA/RTO/RPO provienen de documentos de una versión anterior. No constituyen decisiones ni compromisos del alcance actual.

El informe de monitoreo 3.2.2 conserva un ejercicio de control con tareas, fechas y estados simulados. Es útil como material didáctico, pero no debe leerse como evidencia de gasto o ejecución de producto.
