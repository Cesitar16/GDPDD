\section{Recomendaciones}

\begin{itemize}
  \item Mantener como alcance vigente las diez semanas y el presupuesto estimado EP3 de \$10.506.069 CLP, separando claramente estimaciones de ejecución observada.
  \item Preservar los datos originales; repetir entrenamiento y validación sólo mediante los pipelines reproducibles, sin ajustar transformaciones con datos de prueba.
  \item Reportar la igualdad de ROC-AUC en test entre baseline y XGBoost one-hot, junto con el mayor promedio CV de la logística CPU. No presentar la selección GPU como mejora predictiva.
  \item Mantener los scores como no calibrados y las cinco filas de ejemplo como sintéticas.
  \item Antes de cualquier aplicación clínica, verificar target y dominios, obtener datos representativos y autorizados, validar localmente y evaluar subgrupos con tamaño suficiente; acordar métricas y umbrales con responsables clínicos.
  \item Mantener revisión humana y trazabilidad. No diagnosticar, tratar, priorizar ni automatizar decisiones con este prototipo.
  \item Conservar las tareas, horas y estados del informe 3.2.2 bajo la etiqueta de ejercicio simulado; no sumarlos al presupuesto ni tratarlos como avance ejecutado sin evidencia independiente.
\end{itemize}
