\section{Herramientas y stack implementado (D5)}

El stack comprobable en la actividad 3.1.2 se centra en Python y herramientas de ciencia de datos para un prototipo local reproducible.

\begin{description}[style=nextline]
  \item[Python y uv] Entorno del proyecto declarado en \texttt{pyproject.toml}, fijado en \texttt{uv.lock} y reproducible mediante \texttt{uv sync}.
  \item[Pandas y NumPy] Lectura, auditoría y preparación de datos tabulares.
  \item[Scikit-learn] Pipelines, codificación, escalado, regresión logística comparativa, partición y validación cruzada.
  \item[XGBoost con CUDA] Clasificador basado en árboles y candidato final ejecutado localmente en GPU NVIDIA.
  \item[Joblib] Serialización del pipeline entrenado, incluyendo transformaciones y modelo.
  \item[Jupyter] Registro ejecutable del flujo de análisis, gráficos, evaluación y cinco predicciones sintéticas.
\end{description}

PostgreSQL, SHAP, FastAPI, Streamlit, Docker, GCP, Vertex AI y MLOps aparecen en propuestas o versiones anteriores; no están implementados en la actividad actual. El script de inferencia es una automatización batch local, no un servicio API ni una aplicación institucional.
