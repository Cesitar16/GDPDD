\section{Alternativa local y estado implementado (antecedente D3)}

La ejecución comprobable del proyecto ocurre en entorno local. El entorno Python se fija mediante \texttt{uv}; el notebook entrena XGBoost con CUDA y registra el dispositivo \texttt{cuda:0}. La GPU utilizada fue una NVIDIA GeForce RTX 4060 Laptop GPU. Para el comando de inferencia, el modelo guardado se carga localmente y procesa un CSV; los datos de ejemplo son sintéticos.

Este entorno local es el utilizado para desarrollo y demostración, no una infraestructura hospitalaria on-premise. No se han documentado servidor institucional, red clínica, base de datos productiva, controles corporativos, respaldos, SLA ni continuidad. Las estimaciones de hardware y operación de versiones anteriores se consideran fuera del alcance actual.
